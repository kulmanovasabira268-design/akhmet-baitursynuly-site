# Ахмет мұрасы — қазіргі сабақ

Ахмет Байтұрсынұлының әдеби және ғылыми-педагогикалық мұрасын оқу-тәрбие үдерісінде көрсетуге арналған интерактивті GitHub Pages сайты.

## Құрылымы

- `index.html` — негізгі бет
- `style.css` — дизайн
- `script.js` — интерактивті функциялар

## GitHub Pages арқылы жариялау

1. GitHub-та жаңа repository ашыңыз.
2. Осы үш файлды repository-ге жүктеңіз.
3. **Settings → Pages** бөліміне өтіңіз.
4. **Deploy from a branch** таңдаңыз.
5. Branch: `main`, Folder: `/ (root)`.
6. Save басыңыз.
7. Бірнеше минуттан кейін сайт GitHub Pages URL арқылы ашылады.
